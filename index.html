              Questions people actually ask

              Do I need an account to play?
              No. Every game on BGameWorld opens straight into the browser, free, with nothing to install and no sign-up wall. An account only matters if you want your progress, streaks or daily-challenge score saved and shown on a leaderboard — playing without one works exactly the same, you just won't be ranked.
              What's the daily 7-game challenge?
              Each day the site picks 7 of the 11 games at random, the same 7 for every player that day, so everyone is comparing the same set. Play them from the "Today's challenge" button, add up your score across all seven, and see where you land against everyone else who signed up that day. It's entirely optional — the rest of the site works the same with or without it.
              Do the daily puzzles reset at the same time for everyone?
              Yes. Each game's daily puzzle (Wordezy's word, Sortezy's tube layout, Wordezy Search's word list, and so on) is shared across every player and resets at midnight UTC, so the whole site is solving the same puzzle on the same day no matter where you're playing from.
              Are the games actually free?
              Yes — every game is free to play, with no purchases, subscriptions or paywalled levels. The site is supported by ads rather than charging players.
              Can I play on my phone?
              Yes. Every game is built to run in a mobile browser at the same URL as the desktop version — there's no separate app to download.
              What happens to my information if I sign up?
              Signing up only needs an email, password and the display name shown on leaderboards. You can read exactly what's collected and how to delete it on the privacy policy.
